THINKING-BOT — modelo adaptado de phpOnepience

1. Faz uma cópia de segurança da pasta thinking-bot atual.
2. Extrai esta pasta para C:\laragon\www\thinking-bot (ou outra pasta, se preferires).
3. Inicia o Laragon e abre http://localhost/thinking-bot/public/index.php
4. Testa Início, Atividades, pesquisa por Programação, e Consultar ficha.
5. API de atividades: http://localhost/thinking-bot/api/api.php?rota=atividades

Esta versão mantém a estrutura e o CSS do modelo dos Piratas, adaptando os textos e dados ao Thinking-Bot.
A API está na raiz do projeto, por isso é aberta pelo URL /api/api.php?rota=atividades.
Os dados são arrays PHP, sem base de dados.
